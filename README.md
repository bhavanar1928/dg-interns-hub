# DG Interns Hub – React JS Internship Website

A responsive Job/Internship Landing Website built with React JS for the Week 7 assessment.

## Features

- React functional components
- React Router with Home, Jobs and Contact pages
- Responsive mobile and desktop design
- Internship/job cards
- Search and category filtering
- Apply button interaction
- Contact form with success state
- Reusable Navbar, Footer and JobCard components
- Modern CSS styling without external UI framework

## Tech Stack

- React JS
- React Router DOM
- Vite
- CSS3
- JavaScript ES6+

## Pages

- `/` – Home
- `/jobs` – Jobs and internships
- `/contact` – Contact form

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start development server

```bash
npm run dev
```

### 3. Build for production

```bash
npm run build
```

## Deployment

The project can be deployed to Vercel or Netlify.

For Vercel:
1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Use `npm run build` as the build command.
4. Use `dist` as the output directory.
